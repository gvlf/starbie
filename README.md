# Starbie
A Tamagotchi made by following the tutorial of [SharKingStudios/Starbie](https://github.com/SharKingStudios/Starbie), with minor changes. It's my very first project involving any PCB design work so while this was pretty hard, it was also very enjoyable.

## Project status
Only the PCB is finished, I have made Gerber files for printing of the PCB. The BOM will likely be the same as the tutorial one. For the real deal we will have to wait for Week 6 - Building time!  

## Software
The software is literally the same as the tutorial, with the exception that I changed up the SDA and SCL pins on the ESP32 so those are set to 6 and 7 respectively.
